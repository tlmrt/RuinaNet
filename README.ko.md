Library of Ruina의 비공식 모드입니다. 이 문서는 사용 설명의 번역이며, 모드 인터페이스는 현재 주로 중국어입니다.

## 현재 상태

v1.0의 통신 프로토콜은 **R48**입니다. 양쪽 모두 같은 버전과 호환되는 책장·모드 리소스를 사용해야 합니다. 이전 v3.17.1/R47과 함께 연결할 수 없습니다.

Steam 친구 로비와 릴레이 통신은 실험 기능입니다. 빌드와 자동 검사 712개는 통과했지만, PC 두 대와 Steam 계정 두 개를 사용하는 실제 통신 검증은 아직 완료하지 못했습니다. 모의 API 경계 검사는 이 게임의 App ID 및 모든 네트워크에서 릴레이가 작동함을 보장하지 않습니다. 테스트와 재현 가능한 제보를 환영합니다.

## 시작 방법

1. 양쪽 모두 MOD를 활성화한 방식으로 게임을 실행하고 RuinaNet을 켭니다.
2. 초대장 화면 왼쪽 위의 “联机接待”를 누릅니다.
3. **Steam:** 호스트는 “创建 Steam 房间”, 이어서 “邀请 Steam 好友”를 누릅니다. 게스트는 게임을 실행한 상태에서 초대를 수락합니다. 모드 창에 방 번호가 입력되면 “加入 Steam”을 누릅니다. 호스트에게 받은 방 번호를 직접 입력해도 됩니다.
4. **UDP 직접 연결:** 호스트는 “创建接待室”를 누릅니다. 게스트는 접속 가능한 `IP:포트` 또는 `도메인:포트`를 입력한 뒤 “加入接待”를 누릅니다. 기본 포트는 UDP 27015입니다. 외부 네트워크에서는 UDP 터널, 가상 LAN 또는 포트 포워딩을 별도로 구성해야 합니다.
5. 연결됨 표시를 확인한 후 같은 접대에 참가합니다. 담당 사서를 선택하고 책장 설정을 마친 뒤 준비합니다. 호스트가 전투를 시작하며, 매 막 책장 배정 후에는 양쪽 모두 확인해야 합니다.
6. 일반 환상체 최초 도전과 재도전은 별도의 협동 준비 창을 사용합니다. 호스트가 게임의 원래 도전·재도전 메뉴에서 시작하고 게스트가 수락합니다. 원본 전투 준비 화면에 들어갈 필요는 없습니다.

## 동기화 대상

사서 분담, 핵심 책장, 전투 책장 덱, 귀속 패시브와 외형, 손패, 속도 주사위, 책장 배정과 대상, 합, 주사위 결과 및 전투 상태를 조율합니다. E.G.O 책장은 공동 사용을 조율합니다. 감정·환상체 책장 선택은 현재 호스트가 담당합니다.

## 제한 사항

- 2인 전용입니다. 전투 도중 참가, 호스트 이전, 끊어진 전투에 재접속하는 기능은 없습니다. 연결이 끊기면 해당 전투를 끝내고 다시 연결하세요.
- 지정사서는 호스트가 조작하고 보조사서는 분담에 따릅니다. 사서 한 명만 출전하는 전투에서는 게스트가 관전하며 확인에 참여합니다.
- 층 완전 개방전과 케테르 최종전은 아직 지원하지 않습니다. 특수 기믹, 단계 전환, 여러 무대의 연결은 개별 검증이 필요합니다.
- 환상체 최초 도전은 해당 층 레벨이 같아야 하며, 재도전은 양쪽 모두 해당 도전을 완료해야 합니다.
- 세이브 전송 및 전체 스토리 진행도 공유는 없습니다. 같은 전투 흐름을 수정하는 다른 모드와 충돌할 수 있습니다.
- 손패, 합, E.G.O, 핵심 책장, 패시브, 체력 동기화에 대한 수정이 있으나 모든 조합과 접대를 검증한 것은 아닙니다.

Steam 연결에 실패하면 연결을 끊고 UDP를 시도할 수 있습니다. 같은 Steam 계정으로 두 창을 실행하는 것은 두 계정 검증을 대신할 수 없습니다.

양쪽 버전, 호스트·게스트 구분, 접대·층, 정확한 재현 순서, 스크린샷, 다른 모드와 양쪽 로그를 알려 주세요. Steam·UDP 및 LAN·인터넷·동일 PC 여부도 적어 주세요. 로그의 개인정보를 확인하고 계정 정보나 세이브는 보내지 마세요.
