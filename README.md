# RuinaNet

《废墟图书馆》（Library of Ruina）双人联机实验模组。

**纯 AI 制作，含人量为零。**

许可证：MIT。联机交流与问题反馈 QQ 群：**1130976144**（玩家交流群，非官方）。

- 之前整理的工坊测试包：v3.17.1，IP/UDP 直连，协议 R47。

## 已接入功能

- 普通接待邀请、房间聊天、司书分工与准备确认。
- 核心书页、战斗书页牌组、归属被动和外观配置同步。
- 手牌、速度骰、出牌、目标、拼点、骰子及战斗状态同步。
- E.G.O 共享使用协调；情感／异想体书页目前由房主选择。
- 普通异想体首次挑战与重战使用独立准备界面，无需原版战斗准备界面。

## 使用

从带 MOD 的方式启动游戏，启用本模组。双方使用相同的模组版本及相关书页资源。

进入邀请函界面，点击左上方“联机接待”。

### Steam 好友联机（v1.0 实验功能）

1. 双方先在各自 Steam 账号中启动游戏并启用模组。
2. 房主点击“创建 Steam 房间”，再点击“邀请 Steam 好友”。
3. 客机在游戏运行期间接受邀请，联机面板会填入房间编号；点击“加入 Steam”。也可以手动输入房主显示的房间编号。
4. 等待显示已连接，再进入同一接待。原来的司书分工和双方确认规则继续适用。
5. 只支持一名房主和一名客机。好友离开后应结束本场，再重新连接；不支持房主迁移或断线续战。

若 Steam 房间或连接失败，可点击“断开连接”，改用 IP 直连。此功能需要两个 Steam 账号进行实测，同一账号双开不能替代这项测试。

### IP / UDP 直连

房主点击“创建接待室”；客机输入可达的 `IP:端口` 或 `域名:端口` 后点击“加入接待”。默认 UDP 27015，跨网络需要自行配置 UDP 穿透、虚拟局域网或端口转发。

## 限制

- 仅双人；不支持战斗中途加入、断线续战、存档传输或完整剧情进度共享。
- 楼层专属司书由房主操作，助理司书按分工操作。只允许一名司书的关卡由客机观战并确认。
- 楼层解放战、Keter 最终战暂未接入。特殊异想体与多阶段关卡仍需逐关验证。
- 历史反馈涉及手牌、拼点、E.G.O、核心书页、归属被动及血量同步。已有修复，但未完成全部关卡和跨电脑验收。
- 修改相同战斗流程的其他模组可能冲突。
