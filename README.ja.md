## 現在の状態

v1.0の通信プロトコルは **R48** です。双方で同じバージョンと互換性のあるページ・MODリソースを使用してください。旧v3.17.1/R47とは接続できません。

Steamフレンドロビーとリレー通信は実験的な機能です。ビルドと712項目の自動チェックは通過しましたが、PC2台・Steamアカウント2つでの実通信検証は完了していません。模擬API境界でのチェックは、このゲームのApp IDやすべてのネットワークでリレーが使えることを保証しません。テストと再現手順の報告を歓迎します。

## 遊び方

1. 双方ともMOD対応の起動方法でゲームを起動し、RuinaNetを有効にします。
2. 招待状画面の左上にある「联机接待」を押します。
3. **Steam：** ホストは「创建 Steam 房间」、続いて「邀请 Steam 好友」を押します。ゲストはゲーム起動中に招待を承諾します。MOD画面に部屋番号が入力されたら「加入 Steam」を押します。ホストに教えてもらった部屋番号を直接入力することもできます。
4. **UDP直接接続：** ホストは「创建接待室」を押します。ゲストは接続可能な `IP:ポート` または `ドメイン:ポート` を入力して「加入接待」を押します。既定はUDP 27015です。インターネット越しの接続にはUDPトンネル、仮想LAN、ポート転送などの設定が必要です。
5. 接続済み表示を確認してから同じ接待に参加します。担当する司書を決めて装備を設定し、準備完了後にホストが戦闘を開始します。各幕のページ割り当て後には双方の確認が必要です。
6. 通常の幻想体への初挑戦・再戦では専用の協力準備画面を使います。ホストがゲーム本来の挑戦・再戦メニューから開始し、ゲストが承諾します。通常の戦闘準備画面に入る必要はありません。

## 同期・調整する内容

司書の担当、コアページ、バトルページのデッキ、帰属パッシブと外見、手札、速度ダイス、ページと対象の指定、マッチ、ダイス結果、戦闘状態を調整します。E.G.Oページは共有使用を調整します。感情・幻想体ページの選択は現在ホストが担当します。

## 制限

- 2人専用です。戦闘途中の参加、ホスト移譲、切断した戦闘への再接続には対応していません。切断時はその戦闘を終了し、接続し直してください。
- 指定司書はホスト、補助司書は担当分けに従って操作します。司書1人だけの戦闘ではゲストは観戦し、確認に参加します。
- 階の完全開放戦とケテル最終戦は未対応です。特殊ギミック、段階移行、複数舞台の接続は個別検証が必要です。
- 幻想体への初挑戦では対象の階のレベルが一致している必要があります。再戦では双方が対象の挑戦をクリア済みである必要があります。
- セーブ転送やストーリー進行全体の共有はありません。同じ戦闘処理を変更する他のMODと競合する可能性があります。
- 手札、マッチ、E.G.O、コアページ、パッシブ、HPの同期に修正を加えていますが、すべての組み合わせと接待を検証したわけではありません。

Steam接続に失敗した場合は切断してUDPを試せます。同じSteamアカウントでの二重起動では、2アカウントでの検証を代用できません。
